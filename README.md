# 커뮤니티 타이쿤

옛 온라인 커뮤니티의 분위기를 담아, 게시판과 댓글을 열고 커뮤니티를 키워가는 1인용 타이쿤 게임입니다.

## 프로젝트 소개

처음에는 게시판의 기본 기능을 직접 만들어 보고 싶었습니다. 여기에 롤러코스터 타이쿤처럼 작은 시작에서 점점 키워가는 흐름을 더해, 게임 안에서 골드를 모아 게시판과 댓글 기능을 구매하고 NPC의 활동으로 커뮤니티가 활기를 얻도록 구성했습니다.

경쟁보다 혼자 편안하게 즐기는 경험을 목표로 했습니다. 예전 온라인 커뮤니티가 익숙한 사람, 경영·타이쿤 게임을 좋아하는 사람, 게시판을 꾸미고 성장시키는 재미를 원하는 사람을 떠올리며 만들었습니다.

## 주요 기능

- 회원가입·로그인과 사용자별 게임 진행 상태 저장
- 골드를 사용해 게시판, 댓글, 프로필 등 기능 해금
- NPC 게시글·댓글 생성과 활동 보상 반영
- 게시글·댓글 작성, 수정, 삭제, 검색, 페이지 이동
- 프로필과 테마 변경, 이미지 업로드
- 관리자 권한에 따른 별도 기능

## 주요 구현 내용

- Java 8, Spring MVC, JSP, JavaScript, MyBatis, MariaDB 기반으로 구현했습니다.
- 브라우저 JavaScript가 게임 화면과 NPC 활동을 진행하고, 서버는 요청을 확인해 사용자 상태와 게시글·댓글·보상을 DB에 저장합니다.
- 사용자가 새로고침하거나 다시 로그인해도 게임 진행과 작성한 글이 이어지도록 상태를 계정별로 저장했습니다.
- 프로필 이미지와 게시글 첨부파일은 AWS S3에 저장하고, DB에는 파일 정보와 게시글의 연결 정보를 관리합니다.

## 설계하며 고민한 점

처음에는 NPC 글감을 JavaScript 객체에 두면 DB에서 글감을 가져오는 과정이 없어져 더 빠를 것이라고 생각했습니다. 이를 확인하려고 테스트 프로젝트에서 JavaScript에 준비된 글감을 고르는 방식과 DB에서 글감을 조회하는 방식을 반복 요청으로 비교했습니다.

측정한 범위에서는 JavaScript 글감 선택 방식의 서버 응답이 더 빨랐습니다. 다만 이 시험은 글감 선택 후 서버에 요청해 응답을 받는 시간의 비교였습니다. 게시글과 댓글은 두 방식 모두 DB에 저장했기 때문에, 브라우저 화면에 게시글이 표시되기까지의 전체 시간이나 모든 사용 환경에서의 성능 차이를 증명한 결과로 볼 수는 없습니다. 이 과정을 통해 성능을 말할 때는 무엇을 재고 어디까지 확인했는지 함께 설명해야 한다는 점을 배웠습니다.

## 실행 방법

1. Java 8, Maven, MariaDB, Tomcat 환경을 준비합니다.
2. MariaDB에 `src/main/resources/db/schema.sql`을 실행해 새 데이터베이스를 구성합니다. 이 파일은 신규 DB용 스키마입니다.
3. DB 연결 정보를 `JDBC_DRIVER`, `JDBC_URL`, `JDBC_USERNAME`, `JDBC_PASSWD` 환경변수로 설정합니다.
4. Maven WAR로 빌드한 뒤 Tomcat에 배포하고 프로젝트에 접속해 회원가입합니다.

프로필 및 첨부파일 업로드 기능을 사용하려면 AWS S3 설정도 필요합니다. 자격 증명은 저장소에 올리지 말고 로컬 환경변수나 로컬 설정 파일로 지정해야 합니다.

## 기술 스택

`Java 8` · `Spring MVC` · `JSP` · `JavaScript` · `MyBatis` · `MariaDB` · `AWS S3` · `Bootstrap`
